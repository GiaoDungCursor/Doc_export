# Vietnam template catalog

The administrative templates use Nghị định 30/2020/NĐ-CP as their normative
baseline. Page size, margins, national header, motto, document number, place/date,
recipient, signature and distribution areas are generated as separate mapped zones.

Authoritative references:

- Chính phủ — Nghị định 30/2020/NĐ-CP về công tác văn thư:
  https://vanban.chinhphu.vn/?docid=199378&pageid=27160
- Cổng TTĐT Chính phủ — examples for UBND and specialist bodies:
  https://xaydungchinhsach.chinhphu.vn/huong-dan-cac-mau-van-ban-cua-ubnd-cap-xa-119250623155033014.htm
- Cổng văn bản Chính phủ — real issued documents used to test OCR/layout variation:
  https://vanban.chinhphu.vn/he-thong-van-ban?mode=1

Catalog groups:

- Công văn: standard, two-level authority, urgent.
- Reports: general administrative, periodic, specialist, and academic.
- Other common administrative documents: decision, submission, notice, plan,
  minutes, and invitation.
- Finance: VAT invoice and receipt.

The academic report is deliberately institution-neutral. It provides a structured
Vietnamese academic layout but does not claim to be an official template of a named
university. Institution names and branding must be mapped from user data or a legally
provided source template.
